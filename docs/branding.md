# CoverOps Branding

## Product identity

**CoverOps** is the public product and starter-kit brand.

Full repository title:

> CoverOps — Insurance Voice AI SaaS Starter Kit

## Positioning

CoverOps is a development-ready starter architecture for building an
insurance agency Voice AI SaaS.

It includes synthetic browser and telephone demonstrations and reusable
application foundations.

It must not be described as a production-ready insurance SaaS.

## Demo tenant

**Harborline Insurance** is the fictional insurance agency used throughout
the synthetic demo.

Harborline is not the product name.

## Internal names

The Python import namespace remains `insurance_operations`.

Existing database identifiers and migration history also remain unchanged.

These internal names should not be renamed solely for branding because doing
so would create unnecessary migration and compatibility risk.

## Naming rules

Use **CoverOps** for:

- navigation branding
- marketing pages
- metadata
- screenshots
- documentation intended for starter-kit users
- GitHub presentation

Use **Harborline Insurance** only for:

- fictional agency configuration
- demo conversations
- demo FAQs
- screenshots containing tenant data

Use **Insurance Voice AI SaaS Starter Kit** as the descriptive product
category when additional context is useful.
